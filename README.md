# MNDO Messenger

Open, decentralized, and zero-compromise privacy messaging.

MNDO combines the censorship-resistant relay transport of the Nostr protocol with the cryptographically audited Signal Protocol for true End-to-End Encryption (E2EE). 

### 🌐 The Project
- **[MNDO Client](https://github.com/MNDO-Messenger/MNDO):** Our flagship Flutter application featuring military-grade E2EE, encrypted voice notes, and a self-healing WebSocket architecture.
